### [07:48] — Separação Estrita entre Ponto de Milhar e Vírgula Decimal (Padrão pt-BR)
- **Objetivo:** Resolver a mistura de ponto (`.`) sendo interpretado ou exibido ora como separador de milhar, ora como separador de casa decimal.
- **Status:** CONCLUIDO
- **Arquivos Afetados:**
  - `./backend/calculo.py` (Modificado)
  - `./backend/scraper.py` (Modificado)
  - `./frontend/src/VerEstoque.jsx` (Modificado)
  - `./frontend/dist/` (Recompilado com sucesso via `npm run build`)
  - `./docs/vault/Ver_estoque-logbook/2026-11-09.md` (Atualizado)
- **Decisões Técnicas:**
  - **`backend/calculo.py` (`sanitizar_dataframe`):**
    - Remoção de pontos finais residuais (ex: `'180,90.'` ou `'0.'`).
    - Para números com vírgula (ex: `'1.362,1740'`, `'2.410,74'`, `'3,000'`), a vírgula é tratada como único separador decimal, e os pontos são removidos como separadores de milhar.
    - Para números contendo apenas ponto sem vírgula, identifica estritamente padrões de milhar (`^[1-9]\d{0,2}(\.\d{3})+$`, ex: `'1.000'`, `'10.000'`) para remover o ponto, preservando como decimal apenas números puros com ponto (ex: `'0.11'`, `'9.1'`).
  - **`backend/scraper.py` (`parse_numero_flexivel`):**
    - Alinhada a mesma regra de desambiguação para evitar que saldos da intranet como `'1.000'` fossem convertidos para `1.0`.
  - **`frontend/src/VerEstoque.jsx`:**
    - Toda e qualquer casa decimal na interface agora usa estritamente **vírgula (`,`)**, e todo separador de milhar usa estritamente **ponto (`.`)**.
    - Criado helper `formatarPerc` para formatar percentuais no padrão brasileiro (ex: `75,5%` em vez de `75.5%`).
    - Padronizados campos de `Qtd OC`, `Total OC`, `Saldo OP`, percentuais e tooltips.
